# My SID Jukebox

An offline SID jukebox for the **C64 Ultimate**. It finds every `.sid` file on your SD card, USB sticks and
network drive, and plays them at random, right on the C64. No PC, no network server, no HVSC needed: it plays
**your own** collection.

It is the offline companion of [SID Jukebox](https://github.com/Stephan83c/jukebox-sid-c64), which streams
tunes from an online server.

## Requirements

- A C64 Ultimate (tested with firmware 1.2.1).
- The **Command Interface** enabled in the Ultimate menu (the jukebox uses it to read your drives).
- Some `.sid` files on the SD card, a USB stick or a network drive.

## Getting started

1. Copy `mysidjukebox.prg` to your SD card or USB stick and run it from the Ultimate file browser.
2. A title page is shown for 20 seconds (press any key to skip it).
3. On the first run, choose the drives to search (all are ticked) and press **RETURN**.
   The jukebox scans them, including all sub-folders. Expect about 80 seconds for 600 SIDs in 550 folders.
4. Tunes then play at random, 3 minutes each.

The list of tunes is saved in the Ultimate's `/Temp` RAM disk. It survives a reset of the C64, so the next start
is immediate, but it is lost when the C64 Ultimate is switched off. Press **R** to search again after adding new
files.

## Keys

| Key | Effect |
|---|---|
| `SPACE` | next tune (picked at random) |
| `+` / `-` | next / previous subtune of the same file (shown as `Tune x/y`) |
| `L` | loop on/off: replays the same tune when its time is up (`Loop` turns yellow when on) |
| `R` | new search: choose the drives again (`1`-`9` tick/untick, `RETURN` search, `Q` keeps the old list) |
| `Q` | quit to BASIC |

## The screen

- Title, artist and release year from the SID file, and the full path of the file.
- Subtune, elapsed time, and the video standard of the tune (`PAL`/`NTSC`, `50Hz`/`60Hz` or `TIMER`).
- A progress bar for the 3 minutes of the tune.
- The number of the tune in the list (`SID 123 of 631`).

## Drives

- Every drive at the root of the Ultimate is offered (`SD`, `USB0`, `USB1`...), except `Flash` and `Temp`.
- **Network drive**: if the Ultimate has a network link (it appears as `/FTP`, for example `/FTP/NAS/...`),
  it is offered as `FTP`. This folder is hidden from the root listing, so the jukebox looks for it by name.
- System folders are skipped: names starting with `.`, `$`, `#` or `@` (such as `#recycle` or `@eaDir` on a NAS)
  and `System Volume Information`.

## What plays and what does not

- **PSID** files whose code fits in `$0800-$9FFF`, with any number of subtunes.
- **RSID** files are not supported and are skipped silently: they need the whole machine and cannot be stopped
  cleanly.
- Tunes that do not fit in memory, or are not valid PSID files, are skipped with a short message.
- Tempo is corrected when the tune and the C64 use different video standards (for example a PAL tune on an
  NTSC machine). The pitch is not corrected.
- SID files have no song length, so every tune plays for 3 minutes.

## Building from source

The program is written in 6502 assembly for [Kick Assembler](http://theweb.dk/KickAssembler/):

```
java -jar KickAss.jar src/mysidjukebox.asm -o build/mysidjukebox.prg
```

- `src/big.inc` (the big logo) is generated by `outils/mkbig.py` from the C64 character set.
- `essais/` holds the step-by-step experiments the program was built from (directory walk, file access, list,
  player, RSID attempt).
- `outils/` holds PC-side test helpers for the Ultimate's REST API and FTP server (screen capture to PNG,
  simulated key presses).
- `SPEC.md` is the design document (in French).
